# ⚡ NEON TANKS

بازی تانک نئونی روگ‌لایک برای مرورگر — تک‌فایلی، بدون هیچ وابستگی، با **کوپ آنلاین دنیای مشترک** روی Cloudflare Workers.

**🎮 اجرای محلی بدون سرور:** فایل [`public/index.html`](public/index.html) را در مرورگر باز کنید (حالت تک‌نفره کامل کار می‌کند).
**🌐 اجرای کامل (با بخش آنلاین):** `npm install && npm run dev` → <http://localhost:8787>

## امکانات

- روگ‌لایک عمق‌محور با فروشگاه، گجت‌ها، پهپادها و ماژول‌های تصادفی
- ۵ نوع باس + ۳ نوع مینی‌باس با الگوهای حمله‌ی متفاوت (خمپاره‌ی تلگراف‌شده، تلپورت، رگبار حلقه‌ای)
- کمپین ۵ مرحله‌ای (تک‌نفره) + مود Roguelite بی‌پایان
- **کوپ آنلاین تا ۴ نفر در مود Roguelite:** دشمن‌ها، گلوله‌ها، باس و آیتم‌ها برای همه یکی هستند
- ورود سریع: دکمه‌ی «بازی سریع» (اتاق عمومی) یا کد اتاق / لینک `?room=CODE`
- کنترل لمسی کامل برای موبایل (دو پد + دکمه‌های گجت) و آرنای یکسان روی همه‌ی نمایشگرها
- هویت بازیکن = نام دلخواه + شناسه‌ی محلی در `localStorage` (بدون ثبت‌نام، بدون وابستگی به پلتفرم دیگر)

## معماری آنلاین

```
مرورگر میزبان (host)  ── همه‌ی شبیه‌سازی: دشمن، گلوله، باس، آیتم
      |  snapshot 15Hz + رویدادها
      v
Cloudflare Worker  /ws  --->  Durable Object (یک اتاق = یک DO)
      ^                       رله‌ی مجاز، hibernation-safe، انتخاب و مهاجرت میزبان
      |  ورودی 30Hz
مرورگر مهمان‌ها (client) ── فقط رندر + پیش‌بینی تانک خودش
```

- سرور **شبیه‌سازی نمی‌کند**؛ فقط پیام‌ها را با مجوز رله می‌کند (فقط میزبان می‌تواند snapshot بفرستد).
- گلوله‌ها بالستیک محض هستند، پس در snapshot نمی‌آیند: میزبان فقط رویداد «تولد/مرگ گلوله» می‌فرستد و کلاینت خودش حرکتشان می‌دهد. حجم شبکه حدود ۲۰KB/s برای هر بازیکن.
- اگر میزبان قطع شود، قدیمی‌ترین بازیکن باقی‌مانده میزبان می‌شود و همان عمق از نو شروع می‌شود (state دنیا منتقل نمی‌شود).
- هویت بازیکن سمت کلاینت اعلام می‌شود (قابل جعل است). برای این بازی عمداً ساده نگه داشته شده؛ اگر لیدربورد سرورمحور اضافه شد باید امضای سرور جایگزین شود.

## استقرار روی Cloudflare

یک Worker همه‌چیز را سرو می‌کند (بازی + WebSocket)، پس یک دستور کافی است:

```bash
npm install
npx wrangler login
npm run deploy        # -> https://neon-tanks.<subdomain>.workers.dev
```

- `wrangler.toml`: بخش `[assets]` پوشه‌ی `public/` را سرو می‌کند و `src/worker.js` مسیرهای `/ws` و `/api/*` را می‌گیرد.
- Durable Object ها: `GameRoom` (یک نمونه به‌ازای هر کد اتاق) و `Matchmaker` (نمونه‌ی واحد برای «بازی سریع»).
- تست شبکه‌ی محلی روی موبایل: `npm run dev:lan` و باز کردن `http://<ip-کامپیوتر>:8787` از گوشی.

### API

| مسیر | کار |
|---|---|
| `GET /ws?room=CODE&id=..&name=..` | اتصال به اتاق (`&create=1` برای ساخت، `&pub=1` عمومی) |
| `POST /api/room[?pub=1]` | رزرو یک کد اتاق تازه |
| `GET /api/quickplay` | یک اتاق عمومی با جای خالی، یا اتاق تازه |
| `GET /api/room/CODE` | وضعیت اتاق (تعداد اعضا، میزبان، فاز) |
| `GET /api/health` | سلامت سرویس |

## کنترل‌ها

**دسکتاپ:** `WASD` یا کلیدهای جهت‌دار برای حرکت، ماوس برای نشانه‌گیری، کلیک چپ یا `Space` شلیک، کلیک راست گجت اسلحه، `E`/`R`/`F` توانایی‌ها، `Tab` منوی اسلحه، `P` مکث، `M`/`S` صدا.

**موبایل:** پد راست حرکت، پد چپ نشانه‌گیری و شلیک، دکمه‌های گرد پایین برای گجت‌ها. بازی برای حالت افقی (landscape) طراحی شده است.

## تست

```bash
npm run dev          # در یک ترمینال
npm test             # در ترمینال دیگر — ۸۹ بررسی خودکار
```

| سوئیت | چه چیزی را تست می‌کند |
|---|---|
| `tests/room-server.test.mjs` | Durable Object: انتخاب و مهاجرت میزبان، قواعد رله، ظرفیت اتاق، بازی سریع، keepalive |
| `tests/coop-basics.test.mjs` | دو مرورگر واقعی: پیوستن با لینک، همسان بودن دنیا، ورودی مهمان، پیش‌بینی، مهاجرت میزبان |
| `tests/coop-flows.test.mjs` | دروازه‌ی رلیک، سقوط و احیا، پایان ران و پاداش هر بازیکن |
| `tests/solo-and-mobile.test.mjs` | رگرسیون تک‌نفره: کمپین، مکث، Forge/Shop، نام، `?debug=1`، چیدمان موبایل |

سوئیت‌های مرورگری به Chromium نیاز دارند: `npx playwright install chromium`.

## عیب‌یابی

- `?debug=1` را به آدرس اضافه کنید تا خطاهای زمان اجرا روی صفحه نمایش داده شوند.
- `?server=wss://...` سرور چندنفره‌ی دیگری را جای همین origin می‌گذارد (برای تست).
- `npm run tail` لاگ زنده‌ی Worker.
